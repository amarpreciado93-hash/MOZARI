# Mozari

Plataforma web para crear tours virtuales 360. Un producto de R360.

Propietario: Carlos Amar Preciado Cruz (R360). Todo el código y la marca son de su propiedad.

## Documentos base

- [Producto](docs/PRODUCTO.md): qué es Mozari y qué hace
- [Decisiones](docs/DECISIONES.md): registro de cada decisión importante y por qué se tomó
- [Plan v0.1](docs/PLAN.md): bloques de trabajo hasta la primera versión

## Reglas del proyecto

1. Nada se borra ni se reescribe sin dejar registro en `docs/DECISIONES.md`.
2. Cada cambio se guarda con una descripción clara de qué se hizo.
3. Un tour publicado nunca se rompe por una actualización: cada tour guarda la versión con la que se publicó.
4. Antes de cada versión se prueba en Mac, Windows, iPhone y Android.
